# カード効果と裁定

## 原文と実行処理

- 表示用の名前・能力値・日本語原文・画像は既存の `src/data/*.json` を維持する。
- 実行する効果は `packages/game-core/src/engine.ts` のカード ID ごとの処理。常在キーワードとスキル定義は `model.ts`。
- 原文を実行時に自然言語解析しない。操作・対象・数値・条件を TypeScript で明示する。
- `data/cardEffects.json` と `cardEffectSchema.ts` は初期の宣言的 JSON 形式の試案（3枚）。**現在のエミュレータはこの試案を実行しない**。将来 DSL に移す場合も、実行定義を二重管理しない。

## 「奪う」「減らす」「食べる」「回復」

| 表現 | core の処理 | 挑発 | パンケーキ |
| --- | --- | --- | --- |
| 奪う | `points(..., 'steal')` | 防ぐ | 一度防ぐ |
| 減らす | `points(..., 'reduce')` | 防がない | 防がない・回数も消費しない |
| 食べる | `points(..., 'eat')` | 防ぐ（貫通の暫定ルールあり） | 一度防ぐ |
| 回復 | `heal(...)` | 無関係 | 無関係 |

`s_19` の原文に従い、挑発で奪取が防がれた時はパンケーキを消費しない。ポイントは0未満にならず、回復は現在の最大値まで。

「奪う」で自分も回復するかは原文だけでは決まらない。開始画面の `stealHeals` で指定する。初期設定は回復なし。回復ありの場合は相手が実際に失った点数だけ回復する。

## お菓子の10・5

ユーザー指定の「初めて10になったら青いおはじきと1枚ドロー」を、10以下 / 5以下への初回到達として実装。各1回、回復後も使用済みを維持する。ドローは対象の山札クリックで1枚ずつ解決し、その間は次の操作を待つ。12→4では両方が発動し2枚引く。比較はポイント変更直前と直後で行う。初期設定が10以下なら、10の通過によるドローは発生しない。

## 基本ルールの暫定値

| 項目 | 現在の実装 | 開始画面で変更 |
| --- | --- | --- |
| デッキ | 幼女20 / お菓子10、動物さんソーダ各1枚 | 不可 |
| 先攻・後攻 | 双方のダイスを振り、大きい目が先攻。同値は振り直し | 不可 |
| 初期手札 | 幼女3 / お菓子0、山札から手動ドロー、引き直しなし | 枚数のみ可 |
| 初期ポイント | 12、最大値も12 | 可 |
| PP | 各自のターン数 + 追加最大PP、上限10。開始時に補充、前借り分を控除 | 上限のみ可 |
| 通常ドロー | 幼女1枚を手動ドロー、先攻最初のターンはなし | デッキ・先攻ドロー可 |
| 山札切れ | ログに残し、ドロー不発 | 敗北にも変更可 |
| 場 | 各7人、手札から出す場合は満員なら拒否 | 不可 |
| 攻撃 | 各ターン1回、通常は登場ターン攻撃不可、幼女同士は同時ダメージ | 不可 |
| 突撃 / 早食い | 突撃は登場ターンに幼女へ、早食いは幼女・お菓子へ攻撃可能 | 不可 |
| 防衛 | 防衛がいる間、他の幼女に攻撃できない | 可 |
| 貫通 | 防衛を無視。挑発を無視してお菓子を食べられる | 挑発の扱いのみ可 |
| 勝敗 | 効果の各処理後にポイント0を判定。同時0は引き分け | 不可 |

これらは正式ルールの確認が必要。特に挑発 / 防衛 / 貫通の範囲、先攻後攻の差、通常ドローはプレイ感に大きく影響する。

## 効果の解決順と追加の確認事項

- 使用履歴は対象カードの効果を組み立てた後に追加する。「既に」は今回を含めず、「このカードを含めて」は明示的に今回を足す。
- お菓子扱いでない裏メニューは、うぃまるのダメージ防止や次のお菓子の倍化を発動させない。
- 倍化はダメージ / 回復 / 強化 / ドロー枚数に反映する。対象人数は増やさない。キーワードと単発の防止効果は重複させない。複雑な検索・破壊連動・支払いとの組み合わせは公式裁定を要確認。
- 対象がいない処理は不発になり、後続の処理へ進む。手札がなく捨てられなくても、かんらん / オフティ二の後続処理は行う。一方ドーナツは捨てた時だけ付与する。
- 効果の処理中にHP0になった幼女は破壊する。破壊時効果はキュー末尾へ追加する。同時破壊の細かい優先順と、攻撃前効果による破壊時能力の割り込み順は要確認。
- さら / みゅーとんは原文の各文を順に実行し、破壊できなくても同名を出す。破壊成功が必要かは要裁定。
- まこぽにの +1/+1 は手札から出た時のいのむーの有無で付与する。常時条件付きの能力として出入りに連動させるかは要裁定。
- ストラの前借りは同一ターンおよび連続する自分のターンで再使用不可としている。
- 公開した手札は本人の手札に公開表示を付ける。CPU対戦の相手の公開カードも表示する。

公式の裁定を受け取ったら、この文書に出典と具体例を追記し、対応する core の処理を変更する。
