# 盤面エミュレータ

`npm run dev` → `/game/`。いちごの幼女31種類・お菓子28種類、通常プレイアブル6種類を対象にしたローカル対戦。拡張プレイアブルと他フルーツは開始時に拒否する。

## はじめる

- 「新しい対戦」で CPU / 両側操作、双方のデッキ、必要なら基本ルール設定を選ぶ。
- ログイン不要のおためしデッキを用意。Google ログイン後は Firebase に保存したデッキを選べる。
- 幼女20枚、お菓子10枚を実際にシャッフルする。動物さんソーダは各1枚。使用できない保存デッキには理由を表示する。
- 初期手札は暫定で幼女3枚。初期ポイント12、各自の最初のターンは1PP。設定と裁定の詳細は `card-effect-rules.md`。

## カードとターン

- 手札をホバー / キーボードフォーカスすると持ち上がり、カードと原文を確認できる。
- 手札を選択して「場に出す」「お菓子を使う」を押す。幼女は自分の空き枠へドラッグしても出せる。
- 使用可能な手札は緑に発光する。PPを消費し、効果に選択があればダイアログで対象や引くデッキを指定する。
- 攻撃可能な場の幼女を押し、「攻撃する対象を選ぶ」から相手の幼女またはお菓子ポイントを押す。
- プレイアブルの肖像からスキルの効果・残り回数を確認して使用する。
- 「ターン終了」で相手に手番を渡す。CPU は手札、スキル、攻撃、効果の選択を自動操作する。簡易戦略であり最適手を探索するAIではない。

## 盤面の表現

- チェック柄と薄いロゴ、7枠×2列、左右の山札・捨て札を参照画像に合わせる。大型の VR 操作用球体は表示しない。
- 山札は残り枚数分のカード層を描く。ドローすると実際に1層減り、0枚なら EMPTY になる。
- ポイントが初めて10以下・5以下へ下がると、その位置に小さい青いおはじきを置き、お菓子を各1枚引く。12→4なら両方発動する。回復して再度下がっても再発動しない。
- 幼女が受けたダメージは白い `−数字` のおはじき、追加最大PPは白い `+数字` のおはじきで表示する。
- 場のカードには現在の攻撃力・残りHPとキーワードを表示。使用済みカードは傾けて暗くする。
- ロゴは `public/images/game/cafe-logo.svg` の描き起こし。原本との完全一致ではない。猫まんじゅう / ギガプリンは仮のトークン表示。

## 両側操作・保存

- 対戦中も CPU / 両側操作を切り替えられる。CPU は一時停止可能。
- 両側操作では手番に応じて盤面を反転。反対側を見ることもできる。
- 山札を押すと追加ドロー。プレイアブルの画面でポイント / 現在PP / 追加PPを調整。場のカードの画面でダメージを調整する。
- 「一手戻す」は直近20操作まで。対戦ログも表示する。
- 途中状態はブラウザに自動保存し、再読み込みで復元する。オンライン同期・別端末での再開は未実装。
- 狭い画面は横スクロールする。机全体を操作する用途では横長画面または全画面表示を推奨。
