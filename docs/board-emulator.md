# 盤面エミュレータ

`npm run dev` → `/game/`。いちごの幼女31種類・お菓子28種類、通常プレイアブル6種類を対象にしたローカル対戦。拡張プレイアブルと他フルーツは開始時に拒否する。

## はじめる

- 「対戦の準備」で CPU / 両側操作、双方のデッキ、必要なら基本ルール設定を選ぶ。
- ログイン不要のおためしデッキを用意。Google ログイン後は Firebase に保存したデッキを選べる。
- 幼女20枚、お菓子10枚を実際にシャッフルする。動物さんソーダは各1枚。使用できない保存デッキには理由を表示する。
- 盤面中央のダイスを振る。大きい目の側が先攻。同じ目なら振り直す。
- 光る山札を押して1枚ずつ引く。双方の初期ドローが終わると先攻のターンを開始する。
- 初期手札は暫定で3枚。毎回、幼女 / お菓子のどちらから引くか選ぶ。初期ポイント12、各自の最初のターンは1PP。設定と裁定の詳細は `card-effect-rules.md`。

## カードとターン

- 画面下端に扇状の手札を重ねる。「手札」で大きく広げ、カード画像を確認する。「盤面へ」で場へ集中できる。
- 手札を選択して「場へ」から空き枠を押す。お菓子は「使う」。指やマウスで持ち上げて場へ運ぶこともできる。
- 使用可能な手札は緑に発光する。PPを消費し、効果に選択があれば場・手札・山札を直接押して指定する。その他の選択肢は盤面下に表示する。
- 攻撃可能な幼女を持ち上げ、光る相手にぶつけて攻撃する。カード選択→対象クリックでも同じ演出になる。挑発がいる間は挑発を持つ幼女だけ選択可能。
- プレイアブルからスキルのモーダルを開く。効果・PP・残り回数をスキルごとの大きなボタンにまとめる。
- 「ターン終了」で相手に手番を渡す。通常ドローも好きな山札を押して引き、引き終えるまでプレイやターン終了はできない。CPU は手札、スキル、攻撃、効果の選択を自動操作する。簡易戦略であり最適手を探索するAIではない。

## 盤面の表現

- チェック柄と薄いロゴ、7枠×2列、左右の山札・捨て札を参照画像に合わせる。大型の VR 操作用球体は表示しない。
- 山札は残り枚数分のカード層を描く。ドローすると実際に1層減り、0枚なら空の枠になる。山札から手札へ移動して表になる演出を付ける。
- ポイントが初めて10以下・5以下へ下がると、その位置に小さい青いおはじきを置き、お菓子デッキを押して各1枚引く。12→4なら両方発動する。回復して再度下がっても再発動しない。
- 幼女が受けたダメージは白い `−数字` のおはじき、追加最大PPは白い `+数字` のおはじきで表示する。
- コストや元の能力値はカード画像を使い、重ねて表示しない。能力の変化は白いおはじきで表示。キーワードも表示する。使用済みカードは傾けて暗くする。
- ロゴは `public/images/game/cafe-logo.svg` の描き起こし。原本との完全一致ではない。猫まんじゅう / ギガプリンは仮のトークン表示。

## 両側操作・保存

- 対戦中も CPU / 両側操作を切り替えられる。CPU は一時停止可能。
- 両側操作では手番に応じて盤面を反転。反対側を見ることもできる。
- 追加ドローは両側操作のスキル欄で実行する。カウンターでポイント / 追加PP、サイドパネルで現在PPやダメージを調整できる。通常の山札クリックは要求されたドローだけを行う。
- 「一手戻す」は直近20操作まで。対戦ログも表示する。
- 小さい常設の説明文やログ表示を置かず、山札の持ち上がり、光る対象、衝突演出で操作を示す。準備・詳細・ログはメニュー、スキルはモーダルで開く。
- 途中状態は初期ドローの途中もブラウザに自動保存し、再読み込みで復元する。オンライン同期・別端末での再開は未実装。
- 狭い画面は横スクロールする。机全体を操作する用途では横長画面または全画面表示を推奨。

盤面文字には Yomogi の必要文字を同梱する。ライセンスは `public/fonts/Yomogi-OFL.txt`。
