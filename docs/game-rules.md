# ぷぷりえーる：ルール・裁定集

この文書は、この会話でユーザーから提供された能力説明・イチゴ／ぶどうのFAQと、これまで指定された対戦開始手順を整理したもの。ゲーム処理を実装するときの参照先とする。

本文の「ぶどうFAQ⑥-1」などは、提供されたFAQのグループ番号と、その中の質問の順番を表す。カード名の表記は提供資料に合わせる。数値や例外が明示されていない部分は推測で補わない。

エミュレータの現在の処理・暫定設定・実装との差分は [カード効果と実装状況](card-effect-rules.md) に記載する。ぶどうの裁定も、カード効果の実装と検証に使う。

**最新のユーザー指定を優先する。早食いは登場直後に幼女・お菓子へ攻撃可能、突撃は幼女へのみ。防衛はお菓子と防衛を持たない幼女への攻撃を防ぎ、貫通は防衛を無視する。挑発は選択する効果の対象集中と、お菓子を奪う効果の無効化。「X個奪う」は相手をX減らし、自分をX増やす。**

## 1. 対戦開始と初期手札

1. ダイスを順に振り、大きい目の側が先攻・後攻を選ぶ。同じ目なら振り直す。
2. 先攻は3枚、後攻は4枚引く。双方は順番を待たず、同時に初期手札を引ける。
3. 引くたびに、幼女デッキ・お菓子デッキのどちらから引くかをプレイヤーが選ぶ。通常のターンドローも、山札をその都度選ぶ。
4. 初期手札を確認し、変えたいカードを交換できる。最初に引いたカードそれぞれにつき1回まで。交換後に引いたカードを続けて交換することはできない。エミュレータでは、交換するカードをまとめて選び、交換は1回で行う。
5. 双方が手札を決定してから対戦を開始する。

初期手札の交換でカードを山札に戻す順番・シャッフルの方法は、提供されたルールでは未指定。現在のエミュレータで採用している方法は実装状況の文書に記載する。

## 1.1 自分のターンとその他のルール（説明④・⑤）

| 項目 | ルール |
| --- | --- |
| ドローフェイズ | ターン開始時に幼女・お菓子のどちらかから1枚引く。先攻1ターン目も含む。 |
| 行動 | 幼女・お菓子のプレイ、プレイアブルのスキル、場の幼女の行動を、コストの範囲内で順不同に行える。 |
| PP | 自分の1ターン目は1PP、2ターン目は2PP。基本は自分のターン数と同じで、最大値の上限は12。使い残したPPは相手のターンの間も残り、次の自分のターン開始時に補充値で置き換わる（6.1）。 |
| 後攻5ターン目 | ターン開始時に現在PPを追加で2増やす。最大PPには数えない。恒久的な増加がなければ最大PPは5のまま、現在PPは7になる。回復は最大PPまでで、この+2は回復しない。使い残したPPは上と同じく相手のターンの間だけ残る（2026-10-18 ユーザー裁定）。 |
| お菓子ポイントの10・5 | 初めて10以下・5以下へ下がったとき、それぞれお菓子デッキから1枚引く（強制。引かない選択はない）。回復して再び下がっても再発動しない。 |

| デッキ切れ | ライブラリアウトによる敗北はない。空のデッキからは補充できず、両デッキが空ならターン開始の補充をせず続ける。 |
| 膠着による決着 | お互いのプレイヤーが「デッキからカードを引く、カードをプレイする、場の幼女の行動、プレイアブルスキルの使用」のいずれも行わない状態が3ターン続く、またはその状態が確定した場合、試合は強制終了する。残りお菓子ポイントが多い方が勝利し、同数なら後攻側が勝利する。 |
| 場の幼女 | 通常は登場ターンに行動不可。次の自分のターンから攻撃・お菓子を食べる行動ができる。早食い・突撃の例外に従う。 |

手札上限はターン終了時点で判定する。後続のターン終了時効果によって増える手札については、ぶどうFAQ⑤-2の裁定を保持する。

## 2. 用語と能力

### お菓子ポイントと空腹状態

**空腹状態**とは、自分のお菓子ポイントが **5以下** の状態。

「食べる」「奪う」「減らす」は、効果文の表現を区別して扱う。

| 表現 | 提供された裁定から分かること |
| --- | --- |
| 食べる | 幼女によるお菓子への攻撃と、カードの「食べる」効果を区別して解決する。ふろんとの直接攻撃では攻撃力3と攻撃時効果2を合わせ、5個食べられる。ポイントの変動が無効でも「食べた」履歴は残る裁定がある。 |
| 奪う | 相手のお菓子ポイントをX減らし、自分のお菓子ポイントをX増やす。相手の挑発がいる場合は効果全体を無効化し、両者のポイントを変えない。 |
| 減らす | 「食べる」「奪う」と同じ処理に置き換えず、カード原文の指定を保持する。挑発では防がれない。 |
| 回復・値の変更 | 現在のお菓子ポイントの最大値を超えない。いろはで相手の15ポイントを参照しても、自分の最大値が12なら自分は12まで。 |

「奪う」の減少と回復はいずれも効果文のXを用いる。ポイントが0になった時点で負けになる（エミュレータは0未満を数えない。0未満を使う効果はない）。自分の回復は最大値まで。

### 防衛・挑発・早食い・貫通

| 能力 | ルール |
| --- | --- |
| 防衛 | この能力を持つ相手幼女がいる間、貫通のない幼女はお菓子を攻撃できず、防衛を持たない幼女も攻撃できない。防衛を持つ幼女から攻撃先を選ぶ。 |
| 挑発 | 対象を選択するカード効果・スキルでは、元の対象候補に相手の挑発が含まれる場合、その挑発持ちからしか選べない。お菓子を奪う効果も無効化する。通常の攻撃先を集中させる能力ではない。 |
| 早食い | 場に出てすぐ、お菓子を食べることも幼女を攻撃することも可能。防衛を無視する能力ではない。 |
| 突撃 | 場に出てすぐ相手幼女を攻撃できる。登場ターンのお菓子への攻撃は許可しない。 |
| 貫通 | 防衛を無視し、お菓子や防衛を持たない幼女も攻撃できる。登場直後の行動許可は早食い・突撃によって別に判定する。 |
| 1d6 | 6面ダイスを1回振る。出目は1〜6。 |

防衛は幼女による攻撃先を制限する。挑発は対象を選ぶ効果を制限する。全体効果・ランダム効果は挑発による対象集中を受けない。

### おにごっこ（1d6≧X）

以下の場合、対象となった幼女について1d6を振る。

- 相手幼女から攻撃を受ける。
- 相手のカード効果の選択対象になる。
- 相手のプレイアブルキャラのスキルの選択対象になる。

**X以上なら回避成功**。無効にする範囲は次のとおり。

| 発生元 | 回避成功時の処理 |
| --- | --- |
| 幼女の攻撃 | 攻撃そのものが無効。互いにダメージを与えず、攻撃した幼女は行動済みになる。攻撃時効果も発動しない。 |
| カード効果・スキル | その幼女を対象とした処理を無効化する。他の対象への処理や、追加ドローなどの後続処理まで一括で取り消さない。 |
| 複数の幼女を選ぶ効果 | おにごっこを持つ対象ごとに、それぞれ1d6を振る。 |

おにごっこは重複して持たない（2つ得ても判定は1回で、Xの小さいほうが有効。6.1）。全体効果・ランダム効果には適用しない。

例：猫カフェオレの対象が回避した場合、対象へのダメージは無効になるが、追加の1ドローは行える。（ぶどうFAQ⑥-3）

### かくれんぼ

場に出たターンから、**次の自分のターン開始時まで**、相手幼女の攻撃・相手のカード効果・相手のプレイアブルスキルの選択対象にならない。

- 自ら攻撃した場合は、かくれんぼの効果が消失する。
- 全体効果・ランダム効果からは守られない。
- 効果が切れても、かくれんぼという能力自体は保持する。
- 能力を引き継いで新たに場に出し直すと、かくれんぼが再度発動する。レンテによる奪取もこの扱いになる。
- 効果が切れた後、再びかくれんぼを付与できる。

他の能力と併せ持つ場合：

| 組み合わせ | かくれんぼが有効な間 |
| --- | --- |
| かくれんぼ＋防衛 | かくれんぼが優先。防衛は、かくれんぼが切れたタイミングで実質的に効果を発揮する。 |
| かくれんぼ＋挑発 | かくれんぼ中は選択効果の対象集中は無効。お菓子を奪う効果の無効化は有効。かくれんぼが切れると対象集中も有効になる。 |

### 色おに（フルーツタイプ）

色おにを持つ幼女は、括弧内のフルーツタイプを持つ**相手幼女からのダメージやカード効果の影響を一切受けない**。

おにごっこ・かくれんぼにある「全体効果・ランダム効果には無効」という例外を、色おにへそのまま流用しない。色おにの説明は、該当する相手幼女を発生元とする影響を一切受けないという内容である。同タイプのお菓子やプレイアブルにも適用するという説明はない。

## 3. 対象選択のルール

### 選択する処理

対象候補は次の順に整理する。

1. 効果文の範囲を満たす候補を作る。自分／相手、フルーツタイプ、直前のターンにお菓子を食べた幼女などの条件を先に適用する。
2. 相手のかくれんぼ中の幼女を、選択対象から除く。
3. 対象を選ぶカード効果・スキルでは、残った候補に相手の挑発が含まれる場合、その挑発持ちだけを選べるようにする。自分の挑発は自分の対象選択を制限しない。
4. 対象を選ぶ。おにごっこの対象なら、対象ごとに回避判定を行う。
5. 無効にならなかった対象への処理を解決する。

挑発については最新のユーザー指定を反映。他の選択条件は提供された能力説明・FAQに従う。

| 場面 | 選択できる対象 |
| --- | --- |
| ぶどうタイプを選ぶ効果で、相手の挑発がイチゴタイプだけ | イチゴの挑発は元の候補に入らないため、選択を吸わない。ぶどうタイプから選ぶ。 |
| みゅーとんで自分・相手の幼女を選べる状態に、相手の挑発がいる | 相手の挑発だけを選べる。自分の幼女は選べない。 |
| みゅーとんで自分の場にだけ挑発がいる | 自分の挑発は不利益となる対象集中を起こさず、相手の幼女も選べる。 |
| しゅれいの「2人に4ダメージ」で、候補に挑発1人と非挑発1人がいる | 挑発1人だけに4ダメージ。最初の対象候補を非挑発へ広げない。 |
| おにごっこを持つ2人を選んで4ダメージを与える | 2人がそれぞれ回避判定する。片方の成功で、もう片方への処理まで無効にしない。 |

### 全体効果・ランダム効果

選択する処理と区別する。おにごっこ・かくれんぼによる回避／選択禁止は適用しない。挑発についても「候補から対象を選ぶ」処理の集中と、全体／ランダムへの処理を混同しない。

色おにの発生元に対する免疫は、別の判定として保持する。

## 4. 処理順・履歴・能力の保持

### 攻撃を受けるとき

おにごっこを持つ幼女が攻撃を受け、リンネの手札誘発も使える場合の順序：

1. おにごっこの判定を行う。
2. 成功したら攻撃そのものを無効にし、攻撃した幼女を行動済みにする。攻撃時効果とリンネの手札誘発は発動しない。
3. 失敗したら、このタイミングでリンネの効果発動を宣言できる。
4. 同時タイミングの効果は、自ターン側の効果を先に処理する。

ふろんとの攻撃時にリンネを使う例では、ふろんとの攻撃力・体力の入れ替えが先、リンネのデバフが後。無傷のふろんとは4/1になる。（ぶどうFAQ①-4）

### 効果の文章順と同時処理

- カード効果は上から順に処理する。犬カフェオレで挑発を破壊した後の「お菓子を1個奪う」は、挑発がなくなった状態で判定する。
- 同時タイミングで自分と相手の効果が発生した場合、自ターン側を先に処理する。
- タイミングが完全に一致する盤面のカード効果は、インデックスが古い方を優先する。提示されたラテアートの例では、先に場に出たレンテ／もなかの効果が先になる。
- 手札からプレイしたカードの処理を先に行う裁定がある。とここがいる状態でちょりを出した場合、ちょりのドローと、お菓子を引いた場合の体力バフが先、その後にとここの効果がかかる。
- HP0の幼女を手札から出した場合も、手札から場に出た効果を先に発動し、その後に本体がお昼寝場所へ移る。

### 履歴と現在値を分ける

- スキルの使用回数を初期値へ戻しても、ゲーム中にスキルを使った履歴は消えない。しゅおの追加効果は復活しない。
- ポイント変動を無効にしても「お菓子を食べた」ことまで取り消されない。その幼女は店長の「お仕置き」の対象にできる。
- うゆちの「既に5枚以上」は今回のプレイを含めない。早食いの付与は6枚目から。
- かくれんぼの有効期間が終わることと、かくれんぼの能力を失うことは別。

### 倍化・重複・スキル回数

| 項目 | 裁定 |
| --- | --- |
| おいしくなる呪文 | 重複し、加算で倍率が増える。2回なら3倍。ターンをまたいで持続する。 |
| おにごっこ | 重複して持たない（判定は1回。2つ得たらXの小さいほう。6.1）。 |
| ういまるのバリア | 重複しないが、剥がれた後に再付与できる。 |
| ぶどうレンテのダイスバフ | 重複する。カードテキストに1d6と書かれたダイスに対して発動する。ランダム処理用のダイスには適用しない。 |
| プレイアブルの使用回数 | ゲーム全体での回数。ストラの固有スキルを除き、残り使用回数の範囲内で同じターンに繰り返し・複数種類を使える。ストラは個別の制限に従う。 |

### 山札・手札・お昼寝場所

- ももかが店長／副店長を探す際は、山札の上からめくり、最初に出た該当カードを手札に加える。該当しなかったカードを相手に明示し、山札へ戻してシャッフルする。
- いろはでお昼寝場所からお菓子を戻す際、ゲーム中にプレイしていないカードも選べる。
- ういまるのポイント変動無効化は、山札が空・必要枚数未満でも発動できる。不足時は残っている山札をすべて除外する。除外は1枚ずつ確認してよい。
- ターンエンド時点の判定で9枚だった手札が、ゆうひのターンエンド効果で10枚になっても、1枚を除外せず持ち越せる。
- コストが上がったリンネがお昼寝場所へ行く、または場から手札へ戻ると、コストは1に戻る。

## 7. 今回の資料だけでは確定しない点

- 「減らす」と、挑発以外の各防御能力との一般的な関係。
- 「おいしくなる呪文」が数値・対象人数・キーワード付与などのどこまで倍化するか。加算で3倍になることと、ターンをまたぐことは明示されている（アイスといぬさんだんごは 6.1 で決まった）。
- 初期手札の交換で戻す山札・戻すタイミング・シャッフルの手順。
- デッキ構築枚数など、説明④・⑤やここにない基本ルールの詳細。

これらを、エミュレータの既存設定だけを根拠に確定ルールへ昇格させない。
