# 確認したいこと（未確定の裁定・気になる点）

カードの文やFAQだけでは決めきれず、実装が**どちらかの読み方を仮に選んでいる**箇所と、実装上の気になる点の一覧。
答えが決まったら [ルール・裁定集](game-rules.md) に出典つきで移し、実装を合わせて、この文書から消す。

- 「今の実装」は、その時点でエンジンが実際にしている動き。
- 盤面エディタでその状況を作り、「コードをコピー」で盤面を共有すると確認しやすい（[盤面エミュレータ](board-emulator.md)）。
- 現在のエンジンの処理の一覧は [カード効果の実装状況](card-effect-rules.md)。

### 修正済みの不具合

- **攻撃力と体力の入れ替え**：入れ替え前のダメージが残っていた点を修正。今の攻撃力と残り体力を入れ替え、受けたダメージの記録を消す。入れ替え前のダメージを、しゅおがあとで回復することはない。
- **メロンのえーりんの攻撃終了時効果**：破壊時効果より先に確認していた点を修正。破壊時効果とそこから続く処理・選択をすべて終え、えーりんが場に残っている場合だけ確認する。

この2件は実装の不具合として修正済み。以下の未確定の裁定や、まだ確かめていない項目が解決したという意味ではない。

## 3. 実装上の気になる点

裁定ではなく、作りとして今後手を入れたほうがよさそうなところ。

- **効果の解決順が変わった**：あるステップが新しく積んだ処理は、すでに待っている処理より先に解決する（`effects/resolve.ts`）。いちごのカードも同じ順で動く。破壊時効果は破壊の判定（各ステップの後）で積まれ、待っている処理の後ろに入る。ただし「攻撃終了時」は、破壊時効果とそこから続く処理・選択がすべて終わるまで待つ。
- **エンジン本体にカードIDが直接書いてある**：相手ターンに残りPPを使うカード（`commands/phases.ts` の `usesOffTurnPp`）、条件つきの行動不能（`core/combat.ts` の `canAttack`：ぶどうのゆうひ・ぶどうのもなか）、ほとり丸（`core/zones.ts`）、ちむどんどん！（`core/zones.ts`・`cards/helpers.ts`）。カードが増えるたびにここを直す必要がある。
- **攻撃力0でお菓子を食べたとき、「食べた」と記録しない**：リンネで攻撃力が0になった幼女は、お仕置き・りくすの対象にならない。以前は0でも記録していた。
- **10・5のドローは、攻撃の処理が終わるまで待たせている**（`effects/resolve.ts`）。攻撃の途中でほかの処理が割り込まないための特例。
- **盤面コードの検査が緩い項目**：スキル使用履歴の長さ、イチゴ狩りの期限、手札・山札のカードへの「効果を失った」指定など、普通の対戦では起きない状態を作れる（エンジンは落ちない）。
- **盤面の書き出しで落ちる情報**：場にないカードに付いた能力、プレイアブルを変えたときのスキル使用履歴。

## 7. まだ確かめていないこと

エンジンのテストでは確かめたが、実際の画面や組み合わせでは見ていないもの。

- **画面で見ていないもの**：いのまこ・ちょりのスキル画面、ちょりの反応スキル（相手ターンの確認）、メロンの手札誘発（あみの・ぶらんちゃん）の確認の見え方、奪ったスキル（メロンのレンテ）の表示、スマホなどの狭い画面全般。
- **盤面エディタで設定できないもの**（エンジンと共有コードは持てる）：奪ったスキル、ビデカメの強化、捨てた幼女の数、メロンのゼロオレンジの「行動可能」（条件から毎回計算するので、カードに印が出ない）。
- **テストにない組み合わせ**：色おにと新しい効果（タイプ付与・攻撃力と体力の入れ替え・メロンのぷらむの手札戻し）、メロンのあみのとぶどうのリンネを両方手札に持つとき、メロンのぶらんちゃんで除外する2枚を手で選ぶとき、メロンのえーりんでお昼寝場所のメロンが5人以上のとき、メロンの氷花で山札が3枚未満のとき、メロンのよみで場が満員のとき、メロンのもなかの破壊と同時に両者のお菓子が0になったとき。
- **CPUの弱いところ**：「ふつう」はExスキルを使わない。手札誘発（あみの・リンネ）は使えるときは必ず使う。支払いの判断はほぼ固定（メロンのえーりんは必ず4PP払う、メロンのちょりは必ず4人除外する、メロンのほとり丸は猫まんじゅうを全部捨てる）。対象は攻撃力の高い順で選ぶだけで、損得を見ていない。「つよい」も、自分のちょりの反応スキルを使うかは「ふつう」と同じ判断。ただし攻撃を選ぶ際は、相手が反応スキルを使うと見込み、その代償（次のターンのPP-2）も評価する。
- **表示の小さなずれ**：メロンのいのむー・まこぽには、山札に戻る前にログに「お昼寝場所へ」と出る。メロンのビデカメの山札の公開は、ログに名前が並ぶだけ。
